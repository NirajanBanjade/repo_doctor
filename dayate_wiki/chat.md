# Chat

Lists plan conversations and sends text or image messages.

## Frontend

`App.jsx` (`/chat`) → `pages/Chat.jsx` → `/api/chat/*`

## Backend

`server.js` (`/api/chat`) → `modules/chat/chat.routes.js` → `chat.controller.js` → `chat.service.js` → `message.model.js`

Plan access is owned by [date planning](date-planning.md).
